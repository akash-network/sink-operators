# v0.1.0

Initial standalone Akash Sink operator package for isolated test networks:

- Relayer and reporter commands with software-key creation and validation.
- Bundled Node runtime and Rust header encoder for Ubuntu 24.04 x86-64.
- Systemd units, configuration examples, installation and recovery instructions.
- Signed-transaction recovery, proof/policy tests and release checksums.

This is a preproduction release. `--network testnet` rejects both mainnets; the
systemd units select this mode. Mainnet support awaits the approved production
program interface and deployment. Existing chain, freshness, finality and
reporter-policy checks remain enabled.

Read the installation guide and SECURITY.md dependency dispositions before use.

Verification: 167 service tests and four encoder tests passed. The Linux package
installed on clean Ubuntu without external Node/npm. On an isolated Akash/Solana
localnet, it minted 10 AKT, confirmed an invalid-recipient void and refunded
3 AKT exactly once. Three reporters signed each outcome. Restarting all four
operators preserved journals, settlements, balances and supply without replay.

The localnet used an explicit `sinkdev` build with a 20-second challenge. This is
not release-duration refund or production deployment qualification.
