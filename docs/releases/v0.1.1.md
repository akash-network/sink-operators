# v0.1.1

Relayers and reporters now use the configured AKT deployment address without
rebuilding the package. The deployed contracts must retain the supported
interfaces. Canonical mint, network identity, ownership, freshness and finality
checks remain enabled.

Reporter signing continues to use a raw 32-byte hex secp256k1 private-key file.
Installation instructions now explain existing-key formats and local signing.

Verification of the service change: 172 tests passed. An unreleased Linux
package candidate retained its original IDL while connecting to a new localnet
program and mint. It minted 10 AKT and refunded 3 AKT exactly once. Wrong chain,
genesis and mint checks rejected invalid configurations. Restarting all four
operators preserved journals, settlements, balances and supply.

This remains a preproduction release. Localnet refunds used an explicit sinkdev
20-second challenge. Release artifact verification and production qualification
are separate; no production deployment or release-duration refund is claimed.
